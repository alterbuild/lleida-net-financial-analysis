# Lleida.net: financial analysis presentation

SME Finance group project, EDHEC Business School (IBT4 Lille), 22 October 2026. A single self-contained HTML deck with animated charts and speaker notes (press N; open by default on phones). Arrows or click to move, F for full screen.

- Live deck: https://alterbuild.github.io/lleida-net-financial-analysis/
- PDF version (static slides, with a button that opens the live deck): [Lleida_net_presentation.pdf](Lleida_net_presentation.pdf)
- Presenter mode for a laptop and a projector (stopwatch, slide thumbnails, speaker notes that scroll with the plan): press P in the deck, or open `?presenter`.
